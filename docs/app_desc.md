# Описсние продукта

Это backend приложение - backend для telegram бота, для преподавателя иностранного языка. 

## Описание продукта

Пользователь переходит по [ссылке](https://t.me/pofesora_vale_bot) на бота, нажимает Start в клиенте Telegram.
И получает привественно сообщенеи и под ним видит следующие кнопки:
1. Записаться на пробный пакет (2 урока)
2. Выбрать удобное время для видео знакомства
3. Забрать бесплатный гайд
4. Задать вопросы Валерии.

### Описание кнопок

#### 
Кнопка "Записаться на пробный пакет (2 урока)"
По ее нажатию должно быть отправлено сообщение в телеграм для пользователя телеграм, который указан в .env в переменной RECIPIENT, о том что кто-то хочет записаться на пробный пакет из 2 уровом. Сообщение должно содержать Имя и телеграм ник пользователя который нажал кнопку.

#### 
Кнопка "Выбрать удобное время для видео знакомства"
Аналогично, нужно отправить сообщение для пользователя телеграм который указан .env в переменной RECIPIENT о том что кто-то хочет выбрать время для видео знакомсятва. Сообщение должно содержать имя и телеграм ник пользоватея который нажал кнопку

#### Кнопка "Забрать бесплатный гайд"
По ее нажатию бот дожен отправить пользователю pdf файл

#### Кнопка "Задать вопросы Валерии"
Бот должен попросить пользователя ввести вопрос, который у него есть и затем переслать его для пользователя телеграм который указан .env в переменной RECIPIENT. Сообщение должно содержать имя и телеграм ник пользоватея который нажал кнопку

## Технические моменты
- Бот должен быть реализован с использованием библиотеки [grammY](https://github.com/grammyjs/grammy).
- так проект не предполгает высоких нагрузок и большого числа сообщение, а также у бекенде не будет своего домена, то бот должен работать по методу pooling
